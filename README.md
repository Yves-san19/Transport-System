# Speed Transport System

A menu-driven transport management system developed using Python.

## Features

- 4-digit PIN login
- Passenger registration
- Route selection
- Fare calculation
- Ticket generation
- Input validation

## Routes

| Route | Fare |
|---|---:|
| Accra → Cape Coast | 100 |
| Cape Coast → Accra | 100 |
| Accra → Kumasi | 200 |
| Kumasi → Accra | 200 |

## Technologies Used

- Python
- Functions
- Dictionaries
- Loops
- Conditional statements

## What I Learned

This project helped me practise using functions, dictionaries,
loops, conditional statements, and input validation to create
a menu-driven Python application.
